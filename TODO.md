# Chrome-расширение: страница → Markdown

## Идея

По нажатию кнопки расширение сохраняет открытую страницу в `.md`: основной текст, структуру, изображения, предполагаемый технологический стек, описание видимого интерфейса и карту его поведения. Все выводы о технологиях и работе сайта сопровождаются источником и уровнем уверенности. Для динамических действий, которые нельзя понять из DOM, расширение предлагает короткую запись взаимодействий.

## Пять необычных вариантов

| № | Режим | Что появится в Markdown | Особенность |
|---|---|---|---|
| 1 | **Рентген интерфейса** | Схема секций, список компонентов, ссылки на исходные изображения и признаки технологий | Читатель видит не только текст страницы, но и её устройство; блоки связаны с CSS-селекторами и изображениями |
| 2 | **Путеводитель по действиям** | Сценарии «что нажать → что изменится», формы и их поля, доступные состояния, ошибки и переходы | Расширение записывает действия пользователя и строит проверяемую карту поведения вместо догадок по статичному HTML |
| 3 | **Технологический детектив** | Таблица «технология → улика → уверенность», внешние сервисы, зависимости, признаки сборки | Каждое предположение можно проверить: например, по DOM-атрибуту, URL ресурса или глобальному объекту |
| 4 | **Капсула времени** | Две сохранённые версии Markdown, изменения текста, изображений, интерфейса и технологий | Markdown становится журналом эволюции сайта; полезно для редизайна и наблюдения за конкурентами |
| 5 | **Полевой гид для ИИ-агента** | Краткое назначение страницы, карта областей экрана, доступные действия, ограничения и безопасные точки входа | Файл можно отдать агенту как компактный контекст для последующей работы с сайтом |

**Первый релиз:** «Рентген интерфейса». Он даёт полноценный экспорт страницы, а общие модули затем поддержат остальные режимы.

- [ ] Дать пользователю выбор режима перед экспортом; повторно использовать одно извлечение данных.

### 5. Проверка готовности

- [ ] Проверить длинные страницы, ленивую загрузку, SPA-навигацию, iframe и тёмную тему.
- [ ] Проверить, что Markdown читается без расширения и ссылки ведут на нужные ресурсы.
- [ ] Проверить, что неопределённые технологии и недоступное поведение явно помечены, а не выдуманы.
- [ ] Проверить отсутствие секретов и личных данных в экспортируемом файле.
